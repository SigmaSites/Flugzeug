Offline-READMEs speichern

Diese Dateien funktionieren nach dem Download komplett ohne Internetverbindung.

const htmlContent = await apiResponse.text(); // Vollständiges HTML-Dokument mit CSS-Klassen zusammenbauen const fullHtml = ` README ${htmlContent} `; // Datei-Download im Browser triggern const blob = new Blob([fullHtml], { type: 'text/html' }); const link = document.createElement('a'); link.href = URL.createObjectURL(blob); link.download = 'README.html'; link.click(); } catch (error) { alert('Fehler beim Laden oder Konvertieren der Datei: ' + error.message); } }
